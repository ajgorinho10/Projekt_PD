# Cel projektu
Celem projektu było stworzenie aplikacji, która pomaga śledzić aktywność fizyczną oraz umożliwia otrzymywanie indywidualnie przygotowanych programów treningowych.

# Wykorzystane narzędzia
* Baza danych – Microsoft SQL Server
* Język programowania – Java
* Biblioteki:
  * Spring Boot
  * Lombok
  * Spring Boot security

# Bezpieczeństwo
* Hasła w bazie danych są przechowywane w postaci hashy
* Możliwość aktywacji logowaniem dwuskładnikowym
* Weryfikacja uprawnień dostępu za pomocą sprawdzania ról użytkownika
* Wymaganie długich haseł
* Usuwanie sesji i ciasteczek po wylogowaniu
* Ustawienie czasu wygaśnięcia sesji
* Zabezpieczenie przed atakami typu XSS
* Dokładna obsługa błędów
